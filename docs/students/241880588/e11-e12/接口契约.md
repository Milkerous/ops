# e11e12-1 接口契约（本人核对）

|接口|请求/响应|状态码|本轮实测|
|---|---|---|---|
|POST /v1/jobs|idempotency_key、input(mode/repo/base/target/candidate等)；返回 job_id/status/request_hash|202；输入错误 400；幂等冲突 409|`e12-241880588` 提交返回 202 + `job-031b40cf…`；重复同键同输入返回同一 job_id；同键改 target 返回 409 `IDEMPOTENCY_CONFLICT`|
|GET /v1/jobs/{job_id}|任务状态、trace_id、error|200；不存在 404|轮询由 QUEUED→RUNNING→SUCCEEDED，trace_id=`trace-83008c9c…`|
|GET /v1/jobs/{job_id}/artifacts|阶段清单与 artifact URI/SHA256|200；结果未生成 409|返回 156 项产物|
|GET /v1/jobs/{job_id}/files/{相对路径}|产物文件与 X-Content-SHA256|200；不存在或越界 404|下载 `candidate.patch`，响应头 SHA256=`88074f66…` 与清单、文件一致|

任务状态：QUEUED、RUNNING、SUCCEEDED、FAILED、TIMED_OUT。
输出 envelope 字段：schema_version、job_id、trace_id、kind、commit、status、data、artifacts。
产物 URI 形式：`artifact://job编号/相对路径`，由该任务文件接口解析。
MD 消费前核对：目标 commit、kind、schema_version、内容 SHA256。
基线与目标提交不同是正常的，本链路 full-check 属 base，incremental/repair/recheck 属 target。
