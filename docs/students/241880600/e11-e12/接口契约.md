# E11-E12 接口契约

版本：`e11e12-1`

|接口|请求与响应|状态码|
|---|---|---|
|POST /v1/jobs|body 包含 idempotency_key 与 input（mode/repo/base/target/candidate/fixed_report 等）；返回 job_id、status、request_hash|202；输入错误 400；幂等冲突 409|
|GET /v1/jobs/{job_id}|返回任务状态、trace_id、error|200；不存在 404|
|GET /v1/jobs/{job_id}/artifacts|返回阶段清单、artifact URI、SHA256 和字节数|200；结果未生成 409|
|GET /v1/jobs/{job_id}/files/{相对路径}|返回产物文件及 X-Content-SHA256|200；越界或不存在 404|

任务状态为 QUEUED、RUNNING、SUCCEEDED、FAILED、TIMED_OUT。服务重启时，持久化的未完成 QUEUED/RUNNING 任务改为 FAILED，错误码为 `SERVER_RESTARTED`。

所有阶段 envelope 使用统一字段：schema_version、job_id、trace_id、kind、commit、status、data、artifacts。artifact URI 采用 `artifact://job_id/相对路径`。

消费者必须在修复前核对报告 schema、kind、目标 commit、状态和内容 SHA256。基线提交与目标提交不同是正常情况；报告 commit 必须与当前修复目标一致。
