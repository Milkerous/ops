## 故障与处理

首次运行 H1-H3 时，DRAFT 的 broken Dockerfile 在解析基础镜像时访问 `m.daocloud.io`，服务器 Docker daemon 的失效代理地址 `127.0.0.1:17897` 导致 metadata 请求失败，失败分类为 INFRASTRUCTURE，未进入业务构建。该固定 digest 的 Python 镜像已存在于本机但缺少目标标签；将其标记为原固定标签后，使用新输出目录重跑，三个项目全部通过。该处理只改变本地镜像标签，不修改上游源码、候选 Dockerfile 或测试判定。
